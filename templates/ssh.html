For your server

Optional snippet if you operate the SSH host yourself. Most users only need keys + Activate.

AuthorizedKeysCommand /usr/local/bin/emcssh
AuthorizedKeysCommandUser root

How it works
  1. Generate or paste a public key (your private key stays on this device only).
  2. Activate publishes the public key so SSH servers can authorize you.
  3. OpenSSH validates your key on each connection.
  4. Revoke withdraws authorization — the next login with that key fails.
